**MediCure Enhanced** is a comprehensive, AI-powered healthcare management platform designed to bridge the gap between patients and doctors. It features robust appointment scheduling, secure health record management, and cutting-edge Machine Learning models for disease prediction and personalized diet plans.

---

## ✨ Features

### 👤 User Roles & Authentication
*   **Role-Based Access:** Distinct portals for Patients, Doctors, and Admins.
*   **Secure Auth:** JWT-based authentication with email verification.
*   **Profile Management:** Comprehensive profiles with medical history tracking.

### 🩺 For Patients
*   **AI Disease Prediction:** Predict potential health risks using ML models (XGBoost) based on symptoms.
*   **Smart Diet Planner:** Get personalized diet and exercise recommendations generated by AI.
*   **Appointment Booking:** Seamlessly book slots with doctors.
*   **Health Dashboard:** Visualize health metrics (BP, Heart Rate, BMI) over time.

### 👨‍⚕️ For Doctors
*   **Patient Management:** View patient history and upcoming appointments.
*   **Appointment Handling:** Accept/Reject requests with automated email notifications.
*   **Prescription Management:** (Upcoming) Digital prescription tools.

### 🛡️ For Admins
*   **Verification:** Validate doctor licenses and approve profiles.
*   **System Oversight:** Monitor platform statistics and user activity.

## 🚀 Getting Started (Docker Mode)

The easiest way to run the project is using Docker. It sets up the Database and Web Server automatically.

### Prerequisites
*   [Docker Desktop](https://www.docker.com/products/docker-desktop/) installed and running.

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/2004Shivam/MedicureEnhanced.git
    cd MedicureEnhanced/medicure
    ```

2.  **Create Environment Variables**
    Create a `.env` file in the `medicure` folder:
    ```env
    POSTGRES_DB=medicure
    POSTGRES_USER=medicure_user
    POSTGRES_PASSWORD=secure_password
    POSTGRES_HOST=db
    POSTGRES_PORT=5432
    DEBUG=True
    SECRET_KEY=your_secret_key
    EMAIL_HOST_USER=your_email@gmail.com
    EMAIL_HOST_PASSWORD=your_app_password
    ```

3.  **Build and Run**
    ```bash
    docker compose up --build
    ```

4.  **Access the App**
    *   Web App: [http://localhost:8000](http://localhost:8000)
    *   Admin Panel: [http://localhost:8000/admin](http://localhost:8000/admin)
